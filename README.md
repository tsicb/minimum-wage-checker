# minimum-wage-checker

求人CSVをブラウザ内で解析し、最低賃金割れ・改定前要対応・要確認求人を抽出するGitHub Pages向け静的Webアプリです。

## 特徴
- CSVはブラウザ内で処理し、外部サーバーへ送信しません。
- CP932 / Shift_JIS と UTF-8 の入力に対応します。
- ユーザー提供のコードマスタと最低賃金テーブルをJSON化して利用します。
- 通常賃金、固定残業、試用期間賃金、試用期間固定残業の4軸で判定します。
- 月給等の固定残業代が給与に含まれるか不明な場合は両シナリオを計算します。
- ExcelとCP932 CSVをダウンロードできます。
- Excelは「サマリ」「判定結果」「最低賃金マスタ」の3シートです。

## 使い方
1. GitHub Pagesで `index.html` を開く。
2. CSVダウンロード日を確認する。
3. CSVを選択する。
4. 画面で緊急・改定前要対応・要確認を確認する。
5. Excel / CSVをダウンロードする。

詳細は `docs/spec.md` を参照してください。

## テスト
ブラウザでは `tests/test-runner.html` で代表テストを確認できます。

初版作成時点では35ケースを用意しています。

## データ更新
`data/minimum-wage.json` はユーザー提供の `最低賃金テーブル.xlsx`、`data/masters.json` は各コードマスタCSVから生成しています。最低賃金改定時はマスタJSONも更新してください。

## 外部ライブラリ
- Papa Parse 5.4.1
- encoding-japanese 2.2.0
- ExcelJS 4.4.0

CDNから読み込むため、アプリの起動時にはこれらのライブラリを取得できるネットワーク接続が必要です。CSVデータ自体はブラウザ外へ送信しません。
