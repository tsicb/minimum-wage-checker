# 最低賃金チェッカー 判定仕様 v1

## 目的
求人CSVから最低賃金割れ、改定前要対応、確認が必要な求人を素早く抽出する。金額判定には常に最低賃金テーブルの「新」金額を使用し、CSVダウンロード日と新発効日は緊急度の分類にだけ使用する。

## 入力必須列
求人管理番号 / 公開情報区分 / 雇用形態区分 / 県コード1 / 給与区分 / 給与金額MIN / 平均所定労働時間 / 勤務形態 / 固定残業代の支払額 / 固定残業時間 / 給与区分(試用期間) / 給与金額MIN(試用期間) / 平均所定労働時間(試用期間) / 固定残業代の支払額(試用期間) / 固定残業時間(試用期間)

## 対象外
雇用形態区分が「業務委託」「その他」の求人は対象外。

## 勤務形態が空白
給与区分が時給の場合だけ給与金額MINを新最低賃金と直接比較する。非時給は要確認。固定残業・試用期間の3軸はこのルートでは対象なし。

## 勤務形態が空白でない
### 通常賃金
- 時給: 給与金額MIN
- 日給: 給与金額MIN ÷ 平均所定労働時間
- 月給: 給与金額MIN ÷ 平均所定労働時間
- 年俸: 給与金額MIN ÷ 12 ÷ 平均所定労働時間
- 年収: 同様に参考換算するが、賞与等を含む可能性があるため常に要確認
- 完全歩合制 / その他: 要確認

月給・年俸・年収に固定残業代の支払額がある場合、固定残業代が給与金額MINに含まれるケースと別途支給のケースを両方計算する。両方OKならOK、両方NGならNG、結果が分かれたら要確認。

### 固定残業
固定残業代の支払額が空白なら「固定残業制度なし」と確定し対象なし。値がある場合は、固定残業代 ÷ 固定残業時間を時間単価とし、通常時間額 × 1.25 と比較する。通常時間額に複数シナリオがある場合はすべて比較し、結果が分かれたら要確認。

### 試用期間
通常賃金・固定残業と同じロジックを試用期間列に適用する。試用期間5列がすべて空白なら両軸とも対象なし。固定残業代の支払額(試用期間)が空白なら試用期間の固定残業制度なし。

## 総合判定
- 1軸でもNG: 最低賃金割れ
- NGなし、要確認あり: 要確認
- NG・要確認なし、OKあり: OK
- 雇用形態対象外または全軸対象なし: 対象外

## 緊急度
最低賃金割れの場合:
- 公開中 × 新発効日以降: 緊急
- 公開中 × 新発効日前: 改定前要対応
- 非公開 × 新発効日以降: 公開前要修正
- 非公開 × 新発効日前: 公開前確認

要確認の場合:
- 公開中: 要確認・公開中
- 非公開: 要確認・非公開
- 公開状態コード不明: 要確認・公開状態不明

## 出力
CSVは判定列を左側に追加し、元CSV列を右側に保持する。Excelはサマリ、判定結果、最低賃金マスタの3シートとし、判定結果には時間換算額や差額の詳細列も持たせる。
